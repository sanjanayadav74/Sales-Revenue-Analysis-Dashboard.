# Sales & Revenue Analysis Dashboard

## Overview
This project analyzes the Sample Superstore dataset to identify sales trends, profitability, and business performance using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Dataset
Sample Superstore Dataset

## Analysis Performed
- Data Cleaning
- Data Exploration
- Sales Analysis
- Profit Analysis
- Monthly Sales Trend
- Region-wise Analysis
- Top 10 Products
- Top 10 States
- Business Insights

## Key Insights
- Technology generated the highest sales.
- The West region contributed significantly to total sales.
- A few products generated most of the revenue.
- Higher sales do not always result in higher profits.
